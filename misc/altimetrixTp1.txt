Altimetrix TP1 – Complete interview questions
I extracted the questions from your uploaded interview transcript and organized them in the order they were asked. I have preserved the interviewer's intent and separated direct questions from follow-up questions.
1. Introduction and project architecture
1. Tell me briefly about yourself.
2. Explain your current project and what you are working on.
3. Can you explain your project architecture in detail using a whiteboard?
4. Explain the overall workflow of your Farm Bureau PIC (Producer Incentive Compensation) system.
5. How does the Spring Batch application interact with the database?
6. How does the React UI communicate with the Spring Boot APIs?
7. How does the notification service work in your architecture?
8. How does Informatica load data into your PIC system?
9. How do you calculate commissions for multiple producers or agents?
10. How do you generate reports and notify producers?
2. Authentication and security
11. How do you authenticate business users accessing your application?
12. How does Microsoft Entra authentication work in your application?
13. How does Single Sign-On (SSO) work?
14. What happens if Microsoft Entra is unavailable? How would you handle authentication?
3. Monitoring and troubleshooting
15. Suppose your Spring Boot API fails. How would you identify and track the failure?
16. How do you monitor API errors and request rates?
17. How would you identify whether the problem is caused by an external API, database or application?
18. How would you decide whether Redis caching is required to improve API performance?
4. Database architecture and scalability
19. What is the database write capacity? How many write operations can your database handle?
20. What kind of database architecture are you using?
21. Are you using primary-replica architecture?
22. Why are you not using database replicas in your current project?
23. How do you manage database connection pools?
24. How do you handle large data processing in Spring Batch?
25. How do you handle failures during chunk processing?
26. How do JobRepository and ExecutionContext help restart a failed batch job?
Important database failure scenario
27. Suppose you have one primary database and two replicas. The primary commits a transaction and acknowledges the write, but immediately crashes before the transaction reaches the replicas. A replica gets promoted to primary. How would you prevent the acknowledged transaction from being lost?

This was one of the most important architecture questions in the interview.
5. Java modernization
28. Have you worked on Java migrations, such as Java 8 to Java 17 or Java 20?
29. Have you faced a situation where a microservice was already working properly on an older Java version, but the business requested migration to Java 17 or above?
30. Did you ever challenge or raise concerns about a modernization request when there was no clear business value?
31. Have you defended an existing microservice against unnecessary changes?
6. Firebase Cloud Messaging
32. You mentioned Firebase Cloud Messaging. What was the use case?
33. How do you generate and register device tokens?
34. How does your backend send notifications to the registered devices?
35. How do you handle expired device tokens?
36. How do you handle notification failures and retries?
37. How do you handle failed notifications using a Dead Letter Queue or scheduled retries?
7. Leadership and mentoring
38. In your experience, how do you guide junior developers?
39. How do you assign tasks to junior developers so they can learn and grow?
40. How do you divide complex tasks into smaller responsibilities?
41. How do you help juniors understand debugging, monitoring and coding best practices?
42. How do you balance your own delivery responsibilities with mentoring?
