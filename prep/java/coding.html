Time Complexity is a way to represent the amount of time an algorithm takes to run, in terms of the size of the input. It helps analyze and compare algorithm efficiency without executing them.

Common Time Complexities:


  O(1)   → Constant Time: Accessing an array element by index  
  O(log n) → Logarithmic Time: Binary Search  
  O(n)   → Linear Time: Simple for-loop  
  O(n log n) → Linearithmic Time: Merge Sort, Quick Sort (average case)  
  O(n²)  → Quadratic Time: Nested loops (e.g., Bubble Sort)  
  O(2ⁿ)  → Exponential Time: Recursive Fibonacci  
  O(n!)  → Factorial Time: Solving permutations (e.g., Traveling Salesman)

Example: Linear Time Complexity


  public class TimeComplexityExample {
      public static void main(String[] args) {
          int[] arr = {10, 20, 30, 40, 50};
          int sum = 0;
  
          for (int i = 0; i < arr.length; i++) {
              sum += arr[i]; // One operation per element → O(n)
          }
  
          System.out.println("Sum = " + sum);
      }
  }

Output:


  Sum = 150

In the above example, we traverse the array once. As the input size increases, the time taken grows linearly. Hence, it has a Time Complexity of O(n).

Space Complexity refers to the total amount of memory space that an algorithm or program requires relative to the input size. It includes memory for input values, auxiliary variables, and function call stacks. Space Complexity = Auxiliary Space + Input Size

It is expressed in terms of Big O notation like O(1), O(n), etc.

Example (Java):


  public class SpaceComplexityExample {
  
      // This function demonstrates O(1) space complexity
      public static int sum(int a, int b) {
          int result = a + b; // Only one variable is used
          return result;
      }
  
      // This function demonstrates O(n) space complexity
      public static int[] createArray(int n) {
          int[] arr = new int[n]; // Array of size n
          for (int i = 0; i < n; i++) {
              arr[i] = i * i;
          }
          return arr;
      }
  
      public static void main(String[] args) {
          int result = sum(3, 5);
          System.out.println("Sum: " + result);
  
          int[] squareArray = createArray(5);
          System.out.print("Array: ");
          for (int val : squareArray) {
              System.out.print(val + " ");
          }
      }
  }

Output:


  Sum: 8
  Array: 0 1 4 9 16

In the first function, space complexity is O(1) since only one variable is used.
In the second, it's O(n) because it stores n elements in an array.

An Array is a linear data structure that stores elements of the same type in contiguous memory locations.

Key Features:

  • Fixed size (static memory allocation)
  • Random access using index
  • Efficient for read/write operations

Types of Arrays:

  • 1D Array: Single row of elements
  • 2D Array: Table or matrix-like structure
  • Multidimensional Array: Array of arrays

Example (Java):


          public class ArrayExample {
              public static void main(String[] args) {
                  int[] arr = {10, 20, 30, 40, 50};
  
                  // Accessing elements
                  for (int i = 0; i < arr.length; i++) {
                      System.out.println("Element at index " + i + ": " + arr[i]);
                  }
              }
          }

Time Complexities:

  • Access: O(1)
  • Search: O(n)
  • Insert/Delete (at end): O(1) / O(n) (for shift)

Arrays are widely used in DSA for implementing other data structures like stacks, queues, matrices, etc.
