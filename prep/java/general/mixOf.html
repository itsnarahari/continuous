🧩 Coding Problem: Minimum Meeting Rooms

Problem: Given intervals, find the minimum number of meeting rooms required.

int minMeetingRooms(int[][] intervals) {
  Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
  PriorityQueue pq = new PriorityQueue<>(); // stores end times
  for (int[] m : intervals) {
    if (!pq.isEmpty() && pq.peek() <= m[0]) pq.poll();
    pq.offer(m[1]);
  }
  return pq.size();
}
// Input: [[0,30],[5,10],[15,20]] → Output: 2

⚖️ CAP Theorem
  • Consistency: all nodes see same data.
  • Availability: every request gets a response.
  • Partition tolerance: system works despite network splits.

Tradeoff: In distributed DBs, you can only strongly guarantee 2 of 3 (e.g., Cassandra → AP, MongoDB → CP depending on setup).

🎯 Consistent Hashing in Distributed Systems

Use: evenly distribute keys across nodes, minimal re-distribution on node add/remove.

Used in caching systems (e.g., Redis Cluster) to avoid full rehashing when scaling up/down.

  • Platform threads map 1:1 to OS threads; expensive to create/park; limited by memory/scheduler.
  • Virtual threads (Java 21) are user-mode threads scheduled by the JVM onto a small pool of carrier (platform) threads:
    • Cheap to create (millions possible); blocking I/O parks the v-thread without blocking the carrier.
    • Work best with blocking APIs (JDBC not ideal; use drivers that don’t pin).
  • Pinning: a virtual thread can temporarily pin a carrier when inside long synchronized blocks or some native calls.
// Virtual thread per task
try (var exec = Executors.newVirtualThreadPerTaskExecutor()) {
  Future<String> f = exec.submit(() -> new String(Files.readAllBytes(Path.of("a.txt"))));
  System.out.println(f.get());
}

Parallelize CPU-bound divide-and-conquer tasks with a work-stealing scheduler.

class SumTask extends RecursiveTask<Long> {
  int[] a; int lo, hi; static final int TH = 1_000;
  protected Long compute() {
    if (hi - lo <= TH) { long s=0; for(int i=lo;i<hi;i++) s+=a[i]; return s; }
    int mid=(lo+hi)/2;
    var left= new SumTask(a, lo, mid);
    left.fork();
    long r = new SumTask(a, mid, hi).compute();
    return r + left.join();
  }
}

class TreeNode { int val; TreeNode l,r; }
boolean isBalanced(TreeNode root) { return height(root) != -1; }
int height(TreeNode n){
  if (n==null) return 0;
  int L = height(n.l); if (L==-1) return -1;
  int R = height(n.r); if (R==-1) return -1;
  if (Math.abs(L-R) > 1) return -1;
  return Math.max(L,R)+1;
}

String longestPalindrome(String s){
  int n=s.length(), start=0, len=0;
  for(int i=0;i<n;i++){
    int[] a = expand(s,i,i), b = expand(s,i,i+1);
    if (a[1]-a[0]+1 > len) { start=a[0]; len=a[1]-a[0]+1; }
    if (b[1]-b[0]+1 > len) { start=b[0]; len=b[1]-b[0]+1; }
  }
  return s.substring(start,start+len);
}
int[] expand(String s,int l,int r){
  while(l>=0 && r<s.length() && s.charAt(l)==s.charAt(r)){ l--; r++; }
  return new int[]{l+1,r-1};
}

List<List<Integer>> levelOrder(TreeNode root){
  List<List<Integer>> res = new ArrayList<>();
  if (root==null) return res;
  Queue<TreeNode> q = new ArrayDeque<>();
  q.add(root);
  while(!q.isEmpty()){
    int sz=q.size(); List<Integer> level=new ArrayList<>(sz);
    for(int i=0;i<sz;i++){
      TreeNode n=q.poll(); level.add(n.val);
      if(n.l!=null) q.add(n.l); if(n.r!=null) q.add(n.r);
    }
    res.add(level);
  }
  return res;
}
