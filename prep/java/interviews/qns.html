📌 Problem
Given a List<Integer>, remove duplicates while preserving original order. No Set allowed in your logic.
🧠 Interviewer Checks
  • Knowledge of streams / LinkedHashMap
  • Time–space trade-offs
💡 Approach
  • Use LinkedHashMap / LinkedHashSet-like behavior using map + order.
  • Or simply stream().distinct() for Java 8+
⏱ Complexity

Time: O(n), Space: O(n)


public static List<Integer> removeDuplicates(List<Integer> list) {
    List<Integer> result = new ArrayList<>();
    Set<Integer> seen = new HashSet<>(); // allowed as helper, not final result

    for (Integer num : list) {
        if (seen.add(num)) { // add returns false if already present
            result.add(num);
        }
    }
    return result;
}

📌 Problem
Given a string, return the first character that appears exactly once. If none, return '\0' or Optional.empty().
🧠 Interviewer Checks
  • Use of LinkedHashMap to preserve insertion order
  • Understanding of frequency counting
⏱ Complexity

Time: O(n), Space: O(1) (bounded by charset)


public static Optional<Character> firstNonRepeatingChar(String s) {
    Map<Character, Integer> freq = new LinkedHashMap<>();
    for (char c : s.toCharArray()) {
        freq.put(c, freq.getOrDefault(c, 0) + 1);
    }
    return freq.entrySet().stream()
            .filter(e -> e.getValue() == 1)
            .map(Map.Entry::getKey)
            .findFirst();
}

📌 Problem
Design an LRU cache supporting get(key) and put(key, value) in O(1).
🧠 Interviewer Checks
  • Knowledge of LinkedHashMap access-order
  • Understanding of eviction policies
⏱ Complexity

Time: O(1) average for get/put, Space: O(capacity)


public class LRUCache extends LinkedHashMap<Integer, Integer> {

    private final int capacity;

    public LRUCache(int capacity) {
        super(capacity, 0.75f, true); // accessOrder = true
        this.capacity = capacity;
    }

    public int get(int key) {
        return super.getOrDefault(key, -1);
    }

    public void put(int key, int value) {
        super.put(key, value);
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        return size() > capacity;
    }
}

📌 Problem
Given int[][] intervals, merge all overlapping intervals and return result.
💡 Approach
  • Sort by start time
  • Iterate and merge when current.start ≤ lastMerged.end
⏱ Complexity

Time: O(n log n), Space: O(n)


public static int[][] merge(int[][] intervals) {
    if (intervals == null || intervals.length == 0) return new int[0][0];

    Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
    List<int[]> result = new ArrayList<>();
    int[] current = intervals[0];

    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] <= current[1]) {
            current[1] = Math.max(current[1], intervals[i][1]);
        } else {
            result.add(current);
            current = intervals[i];
        }
    }
    result.add(current);
    return result.toArray(new int[result.size()][]);
}

📌 Problem
Given an int array and k, return k most frequent elements.
💡 Approach
  • Use Map<value, frequency>
  • Use max-heap or sort by frequency
⏱ Complexity

Time: O(n log n) (with sort), Space: O(n)


public static List<Integer> topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int n : nums) {
        freq.put(n, freq.getOrDefault(n, 0) + 1);
    }

    return freq.entrySet().stream()
            .sorted((a, b) -> b.getValue() - a.getValue())
            .limit(k)
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());
}

📌 Problem
Return true if two strings are anagrams (same chars, same counts).
💡 Approach
  • Count chars in array of size 26 (if lowercase) / 256
⏱ Complexity

Time: O(n), Space: O(1)


public static boolean isAnagram(String a, String b) {
    if (a.length() != b.length()) return false;
    int[] count = new int[256];
    for (int i = 0; i < a.length(); i++) {
        count[a.charAt(i)]++;
        count[b.charAt(i)]--;
    }
    for (int c : count) {
        if (c != 0) return false;
    }
    return true;
}

📌 Problem
Given array and target, return indices of two numbers summing to target.
💡 Approach
  • Use hash map of value → index
⏱ Complexity

Time: O(n), Space: O(n)


public static int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>(); // value -> index
    for (int i = 0; i < nums.length; i++) {
        int diff = target - nums[i];
        if (map.containsKey(diff)) {
            return new int[]{map.get(diff), i};
        }
        map.put(nums[i], i);
    }
    return new int[]{-1, -1};
}

📌 Problem
Rotate array to the right by k steps in-place.
💡 Approach
  • Reverse complete array
  • Reverse first k elements
  • Reverse remaining n-k elements
⏱ Complexity

Time: O(n), Space: O(1)


public static void rotate(int[] nums, int k) {
    int n = nums.length;
    k = k % n;
    reverse(nums, 0, n - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, n - 1);
}

private static void reverse(int[] nums, int l, int r) {
    while (l < r) {
        int temp = nums[l];
        nums[l] = nums[r];
        nums[r] = temp;
        l++; r--;
    }
}

📌 Problem
Given 2D matrix, return elements in spiral order.
⏱ Complexity

Time: O(m×n), Space: O(1) extra (output excluded)


public static List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    if (matrix.length == 0) return res;
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        for (int i = left; i <= right; i++) res.add(matrix[top][i]);
        top++;
        for (int i = top; i <= bottom; i++) res.add(matrix[i][right]);
        right--;
        if (top <= bottom) {
            for (int i = right; i >= left; i--) res.add(matrix[bottom][i]);
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--) res.add(matrix[i][left]);
            left++;
        }
    }
    return res;
}

📌 Problem
Given a string, find length of longest substring without repeating characters.
💡 Approach
  • Sliding window with map storing last index of each char
⏱ Complexity

Time: O(n), Space: O(1)


public static int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> map = new HashMap<>();
    int left = 0, max = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (map.containsKey(c)) {
            left = Math.max(left, map.get(c) + 1);
        }
        map.put(c, right);
        max = Math.max(max, right - left + 1);
    }
    return max;
}

📌 Problem
Given a string with ()[]{}, check if it is valid (balanced).
💡 Approach
  • Use stack, push opening, pop on matching closing
⏱ Complexity

Time: O(n), Space: O(n)


public static boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> map = Map.of(
            ')', '(',
            ']', '[',
            '}', '{'
    );
    for (char c : s.toCharArray()) {
        if (map.containsValue(c)) {
            stack.push(c);
        } else if (map.containsKey(c)) {
            if (stack.isEmpty() || stack.pop() != map.get(c)) return false;
        }
    }
    return stack.isEmpty();
}

📌 Problem
Given head of singly linked list, detect if cycle exists.
💡 Approach
  • Floyd’s slow-fast pointer algorithm
⏱ Complexity

Time: O(n), Space: O(1)


static class ListNode {
    int val;
    ListNode next;
    ListNode(int v) { val = v; }
}

public static boolean hasCycle(ListNode head) {
    if (head == null) return false;
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

📌 Problem
Print nodes level by level (BFS).
💡 Approach
  • Use queue, process nodes level by level

static class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int v) { val = v; }
}

public static List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);

    while (!q.isEmpty()) {
        int size = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}

📌 Problem
Given intervals of meetings, find min rooms required so no overlap in same room.
💡 Approach
  • Sort start & end times separately
  • Two pointers to count current concurrent meetings

public static int minMeetingRooms(int[][] intervals) {
    int n = intervals.length;
    int[] starts = new int[n];
    int[] ends = new int[n];
    for (int i = 0; i < n; i++) {
        starts[i] = intervals[i][0];
        ends[i] = intervals[i][1];
    }
    Arrays.sort(starts);
    Arrays.sort(ends);

    int rooms = 0, endPtr = 0;
    for (int i = 0; i < n; i++) {
        if (starts[i] < ends[endPtr]) {
            rooms++;
        } else {
            endPtr++;
        }
    }
    return rooms;
}

📌 Problem
Implement a simple in-memory rate limiter for N requests per second.
💡 Approach
  • Token bucket: refill tokens at fixed rate, consume per request

public class TokenBucket {

    private final int capacity;
    private final int refillPerSecond;
    private double tokens;
    private long lastRefillTimestamp;

    public TokenBucket(int capacity, int refillPerSecond) {
        this.capacity = capacity;
        this.refillPerSecond = refillPerSecond;
        this.tokens = capacity;
        this.lastRefillTimestamp = System.nanoTime();
    }

    public synchronized boolean allowRequest() {
        refill();
        if (tokens >= 1) {
            tokens -= 1;
            return true;
        }
        return false;
    }

    private void refill() {
        long now = System.nanoTime();
        double seconds = (now - lastRefillTimestamp) / 1_000_000_000.0;
        double add = seconds * refillPerSecond;
        if (add > 0) {
            tokens = Math.min(capacity, tokens + add);
            lastRefillTimestamp = now;
        }
    }
}

Implement producer-consumer using BlockingQueue. 

public class ProducerConsumerDemo {

    private final BlockingQueue<Integer> queue = new ArrayBlockingQueue<>(10);

    class Producer implements Runnable {
        public void run() {
            int i = 0;
            try {
                while (true) {
                    queue.put(i);
                    System.out.println("Produced " + i);
                    i++;
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }

    class Consumer implements Runnable {
        public void run() {

                while (true) {
                    Integer val = queue.take();

                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
}
