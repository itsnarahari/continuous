Example (O(n)):


              public class TimeComplexityExample {
                  public static void main(String[] args) {
                      int[] arr = {10, 20, 30, 40, 50};
                      int sum = 0;

                      for (int i = 0; i < arr.length; i++) {
                          sum += arr[i];

                      System.out.println("Sum = " + sum);
                  }
              }

Output:

Sum = 150

One operation per element makes it O(n).

Example (Java):


              public class SpaceComplexityExample {
                  public static int sum(int a, int b) {
                      int result = a + b;  // O(1)
                      return result;
                  }

                  public static int[] createArray(int n) {
                      int[] arr = new int[n];  // O(n)

                          arr[i] = i * i;
                      }
                      return arr;
                  }

                  public static void main(String[] args) {
                      int result = sum(3, 5);
                      System.out.println("Sum: " + result);

                      }
                  }
              }

`sum()` is constant space O(1), `createArray()` is linear O(n).

An Array is a data structure that stores a fixed-size sequence of elements of the same data type in contiguous memory locations.

Key Points:

  • Index-based: Access elements using index (0-based).
  • Fixed Size: Size must be defined at creation.
  • Efficient Access: O(1) time complexity for access via index.
  • Inefficient Insert/Delete (in middle): O(n) time complexity.

Array Diagram:

Example (Java):


              public class ArrayExample {
                  public static void main(String[] args) {
                      // Declare and initialize an array of size 5
                      int[] numbers = new int[5];
      
                      // Assign values
                      numbers[0] = 10;
                      numbers[1] = 20;
                      numbers[2] = 30;
                      numbers[3] = 40;
                      numbers[4] = 50;
      
                      // Access and print values
                      System.out.println("Element at index 2: " + numbers[2]);
      
                      // Traverse the array
                      System.out.print("Array Elements: ");
                      for (int i = 0; i < numbers.length; i++) {
                          System.out.print(numbers[i] + " ");
                      }
                  }
              }

Output:


              Element at index 2: 30
              Array Elements: 10 20 30 40 50

Time & Space Complexity:

  • Access by index: O(1)
  • Insertion at end: O(1) (if space available)
  • Insertion at start/middle: O(n)
  • Deletion: O(n)
  • Space Complexity: O(n) for storing 'n' elements

Why Use Arrays?

  • Simple to use and efficient for static data.
  • Useful as the base for other data structures (e.g., matrices, heaps, stacks).

A Linked List is a linear data structure where each element (called a node) contains data and a reference (link) to the next node in the sequence.

Key Points:

  • Dynamic Size: Can grow or shrink during runtime.
  • Efficient Insertion/Deletion: O(1) time if position is known.
  • No Random Access: Cannot access elements via index directly (O(n) time).
  • Each node contains: data + next pointer.

Singly LinkedList Diagram:

Basic Node Structure (Java):


              class Node {
                  int data;
                  Node next;

                  Node(int data) {
                      this.data = data;
                      this.next = null;
                  }
              }

LinkedList Operations (Java):


              public class LinkedList {
                  Node head;

                  // Add at Beginning
                  public void addAtBeginning(int data) {
                      Node newNode = new Node(data);
                      newNode.next = head;
                      head = newNode;
                  }

                  // Add at End
                  public void addAtEnd(int data) {
                      Node newNode = new Node(data);
                      if (head == null) {
                          head = newNode;
                          return;
                      }
                      Node temp = head;
                      while (temp.next != null) {
                          temp = temp.next;
                      }
                      temp.next = newNode;
                  }

                  // Add at Position (1-based index)
                  public void addAtPosition(int data, int position) {
                      if (position <= 0) {
                          System.out.println("Invalid Position");
                          return;
                      }
                      if (position == 1) {
                          addAtBeginning(data);
                          return;
                      }
                      Node newNode = new Node(data);
                      Node temp = head;
                      for (int i = 1; temp != null && i < position - 1; i++) {
                          temp = temp.next;
                      }
                      if (temp == null) {
                          System.out.println("Position out of range");
                          return;
                      }
                      newNode.next = temp.next;
                      temp.next = newNode;
                  }

                  // Delete at Beginning
                  public void deleteAtBeginning() {
                      if (head != null) {
                          head = head.next;
                      }
                  }

                  // Delete at End
                  public void deleteAtEnd() {
                      if (head == null || head.next == null) {
                          head = null;
                          return;
                      }
                      Node temp = head;
                      while (temp.next.next != null) {
                          temp = temp.next;
                      }
                      temp.next = null;
                  }

                  // Delete at Position
                  public void deleteAtPosition(int position) {
                      if (head == null || position <= 0) {
                          System.out.println("Invalid Position");
                          return;
                      }
                      if (position == 1) {
                          deleteAtBeginning();
                          return;
                      }
                      Node temp = head;
                      for (int i = 1; temp != null && i < position - 1; i++) {
                          temp = temp.next;
                      }
                      if (temp == null || temp.next == null) {
                          System.out.println("Position out of range");
                          return;
                      }
                      temp.next = temp.next.next;
                  }

                  // Print List
                  public void printList() {
                      Node temp = head;
                      while (temp != null) {
                          System.out.print(temp.data + " -> ");
                          temp = temp.next;
                      }
                      System.out.println("null");
                  }

                  public static void main(String[] args) {
                      LinkedList list = new LinkedList();

                      list.addAtEnd(10);
                      list.addAtBeginning(5);
                      list.addAtEnd(20);
                      list.addAtPosition(15, 3);
                      list.printList(); // 5 -> 10 -> 15 -> 20 -> null

                      list.deleteAtBeginning();
                      list.deleteAtEnd();
                      list.deleteAtPosition(2);
                      list.printList(); // 10 -> null
                  }
              }

Output:


              5 -> 10 -> 15 -> 20 -> null
              10 -> null

Time & Space Complexity:

  • Insertion at beginning: O(1)
  • Insertion at end/position: O(n)
  • Deletion at beginning: O(1)
  • Deletion at end/position: O(n)
  • Space Complexity: O(n) for storing 'n' nodes

Why Use Linked Lists?

  • When frequent insertions/deletions are required.
  • Memory-efficient for dynamic size data structures.
  • Foundation for advanced structures like stacks, queues, graphs.

A Doubly Linked List is a type of Linked List where each node contains three parts: data, a reference to the next node, and a reference to the previous node. It allows traversal in both forward and backward directions.

Key Points:

  • Each node has prev and next pointers.
  • Efficient for bidirectional traversal.
  • Insertion/Deletion is easier compared to Singly Linked List at both ends.
  • Requires more memory per node due to extra pointer.

Doubly LinkedList Diagram:

Java Example:


      class Node {
          int data;
          Node prev, next;
          Node(int data) {
              this.data = data;
              this.prev = this.next = null;
          }
      }

      class DoublyLinkedList {
          Node head;

          void insertAtBeginning(int data) {
              Node newNode = new Node(data);
              if (head != null) {
                  newNode.next = head;
                  head.prev = newNode;
              }
              head = newNode;
          }

          void insertAtEnd(int data) {
              Node newNode = new Node(data);
              if (head == null) {
                  head = newNode;
                  return;
              }
              Node temp = head;
              while (temp.next != null)
                  temp = temp.next;
              temp.next = newNode;
              newNode.prev = temp;
          }

          void insertAtPosition(int data, int pos) {
              if (pos <= 1) {
                  insertAtBeginning(data);
                  return;
              }
              Node newNode = new Node(data);
              Node temp = head;
              for (int i = 1; temp != null && i < pos - 1; i++)
                  temp = temp.next;
              if (temp == null || temp.next == null) {
                  insertAtEnd(data);
              } else {
                  newNode.next = temp.next;
                  newNode.prev = temp;
                  temp.next.prev = newNode;
                  temp.next = newNode;
              }
          }

          void deleteAtBeginning() {
              if (head == null) return;
              head = head.next;
              if (head != null)
                  head.prev = null;
          }

          void deleteAtEnd() {
              if (head == null) return;
              if (head.next == null) {
                  head = null;
                  return;
              }
              Node temp = head;
              while (temp.next != null)
                  temp = temp.next;
              temp.prev.next = null;
          }

          void deleteAtPosition(int pos) {
              if (head == null || pos <= 1) {
                  deleteAtBeginning();
                  return;
              }
              Node temp = head;
              for (int i = 1; temp != null && i < pos; i++)
                  temp = temp.next;
              if (temp == null || temp.next == null) {
                  deleteAtEnd();
              } else {
                  temp.prev.next = temp.next;
                  temp.next.prev = temp.prev;
              }
          }

          void display() {
              Node temp = head;
              System.out.print("Doubly Linked List: ");
              while (temp != null) {
                  System.out.print(temp.data + " ");
                  temp = temp.next;
              }
              System.out.println();
          }
      }

      public class Main {
          public static void main(String[] args) {
              DoublyLinkedList dll = new DoublyLinkedList();
              dll.insertAtEnd(10);
              dll.insertAtBeginning(5);
              dll.insertAtEnd(20);
              dll.insertAtPosition(15, 3);
              dll.display(); // Output: 5 10 15 20

              dll.deleteAtBeginning();
              dll.deleteAtEnd();
              dll.deleteAtPosition(2);
              dll.display(); // Output: 10
          }
      }

Output:


      Doubly Linked List: 5 10 15 20 
      Doubly Linked List: 10

Time & Space Complexity:

  • Insertion at beginning/end: O(1)
  • Insertion at position: O(n)
  • Deletion at beginning/end: O(1)
  • Deletion at position: O(n)
  • Space Complexity: O(n) for n nodes (with extra prev pointer)

Why Use Doubly Linked List?

  • Allows bidirectional traversal.
  • Efficient insertions and deletions at both ends.
  • Useful in navigation systems, undo-redo operations, and browser history.

A Circular Linked List is a type of linked list in which the last node points back to the first node, forming a circular structure.

Key Points:

  • Last node’s next points to the head node.
  • No null in the last node, making traversal circular.
  • Can be singly or doubly circular linked.
  • Efficient for applications with cyclic traversals (e.g., round-robin schedulers).

Circular Linked List Diagram:

Java Example:


              class Node {
                  int data;
                  Node next;

                  Node(int data) {
                      this.data = data;
                      this.next = null;
                  }
              }

              public class CircularLinkedList {
                  Node head = null;
                  Node tail = null;

                  // Add at Beginning
                  void addAtBeginning(int data) {
                      Node newNode = new Node(data);
                      if (head == null) {
                          head = newNode;
                          tail = newNode;
                          newNode.next = head;
                      } else {
                          newNode.next = head;
                          head = newNode;
                          tail.next = head;
                      }
                  }

                  // Add at End
                  void addAtEnd(int data) {
                      Node newNode = new Node(data);
                      if (head == null) {
                          head = newNode;
                          tail = newNode;
                          newNode.next = head;
                      } else {
                          tail.next = newNode;
                          tail = newNode;
                          tail.next = head;
                      }
                  }

                  // Add at Position
                  void addAtPosition(int data, int position) {
                      if (position == 1) {
                          addAtBeginning(data);
                          return;
                      }
                      Node newNode = new Node(data);
                      Node temp = head;
                      for (int i = 1; i < position - 1 && temp.next != head; i++) {
                          temp = temp.next;
                      }
                      newNode.next = temp.next;
                      temp.next = newNode;
                      if (temp == tail) tail = newNode;
                  }

                  // Delete at Beginning
                  void deleteAtBeginning() {
                      if (head == null) return;
                      if (head == tail) {
                          head = null;
                          tail = null;
                      } else {
                          head = head.next;
                          tail.next = head;
                      }
                  }

                  // Delete at End
                  void deleteAtEnd() {
                      if (head == null) return;
                      if (head == tail) {
                          head = null;
                          tail = null;
                          return;
                      }
                      Node temp = head;
                      while (temp.next != tail) {
                          temp = temp.next;
                      }
                      temp.next = head;
                      tail = temp;
                  }

                  // Delete at Position
                  void deleteAtPosition(int position) {
                      if (head == null) return;
                      if (position == 1) {
                          deleteAtBeginning();
                          return;
                      }
                      Node temp = head;
                      for (int i = 1; i < position - 1 && temp.next != head; i++) {
                          temp = temp.next;
                      }
                      if (temp.next == tail) {
                          deleteAtEnd();
                      } else {
                          temp.next = temp.next.next;
                      }
                  }

                  // Display list
                  void display() {
                      if (head == null) {
                          System.out.println("List is empty");
                          return;
                      }
                      Node temp = head;
                      do {
                          System.out.print(temp.data + " ");
                          temp = temp.next;
                      } while (temp != head);
                      System.out.println();
                  }

                  public static void main(String[] args) {
                      CircularLinkedList cll = new CircularLinkedList();
                      cll.addAtEnd(10);
                      cll.addAtEnd(20);
                      cll.addAtEnd(30);
                      cll.addAtBeginning(5);
                      cll.addAtPosition(15, 3);
                      cll.display(); // 5 10 15 20 30

                      cll.deleteAtBeginning();
                      cll.deleteAtEnd();
                      cll.deleteAtPosition(2);
                      cll.display(); // 10 20
                  }
              }

Output:


              5 10 15 20 30
              10 20

Time & Space Complexity:

  • Traversal: O(n)
  • Insert at beginning: O(1)
  • Insert at end: O(1) (if tail maintained)
  • Insert at position: O(n)
  • Delete at beginning: O(1)
  • Delete at end: O(n)
  • Delete at position: O(n)
  • Space: O(n) for storing n elements

Why Use Circular Linked List?

  • Useful in applications that require a continuous loop (e.g., round-robin scheduling, multiplayer games).
  • More efficient than singly/doubly linked list in circular traversal cases.

A Stack is a linear data structure that follows the Last In First Out (LIFO) principle, where the last element added is the first one to be removed.

Key Points:

  • LIFO structure: Last inserted element is removed first.
  • Primary operations: push() to insert, pop() to remove.
  • Additional operations: peek() to view top, isEmpty() to check emptiness.
  • Used in recursion, undo features, expression evaluation, and backtracking.

Stack Diagram:

Example (Java):


      public class StackExample {
          static final int MAX = 5;
          int top = -1;
          int[] stack = new int[MAX];

          void push(int val) {
              if (top == MAX - 1) {
                  System.out.println("Stack Overflow");
              } else {
                  stack[++top] = val;
                  System.out.println(val + " pushed");
              }
          }

          void pop() {
              if (top == -1) {
                  System.out.println("Stack Underflow");
              } else {
                  System.out.println(stack[top--] + " popped");
              }
          }

          void peek() {
              if (top == -1) {
                  System.out.println("Stack is empty");
              } else {
                  System.out.println("Top element: " + stack[top]);
              }
          }

          void display() {
              if (top == -1) {
                  System.out.println("Stack is empty");
                  return;
              }
              System.out.print("Stack Elements: ");
              for (int i = 0; i <= top; i++) {
                  System.out.print(stack[i] + " ");
              }
              System.out.println();
          }

          public static void main(String[] args) {
              StackExample s = new StackExample();
              s.push(10);
              s.push(20);
              s.push(30);
              s.peek();
              s.display();
              s.pop();
              s.display();
          }
      }

Output:


      10 pushed
      20 pushed
      30 pushed
      Top element: 30
      Stack Elements: 10 20 30 
      30 popped
      Stack Elements: 10 20

Time & Space Complexity:

  • Push: O(1)
  • Pop: O(1)
  • Peek: O(1)
  • Space Complexity: O(n), where n is the maximum number of elements

Why Use Stack?

  • Simple and efficient for temporary storage of data.
  • Supports recursion and function call stack.
  • Crucial in undo operations, syntax parsing, and backtracking.

A Queue is a linear data structure that follows the First-In-First-Out (FIFO) principle, meaning the element inserted first is removed first.

Key Points:

  • FIFO Order: First element inserted is the first to be removed.
  • Operations: Enqueue (insert), Dequeue (remove), Peek (view front).
  • Used in: CPU scheduling, IO buffers, printers, etc.
  • Types: Simple Queue, Circular Queue, Priority Queue, Deque.

Queue Diagram:

Basic Queue Implementation (Java):


              class Queue {
                  int size;
                  int[] arr;
                  int front, rear;

                  Queue(int size) {
                      this.size = size;
                      arr = new int[size];
                      front = 0;
                      rear = -1;
                  }

                  // Enqueue: Add element at rear
                  public void enqueue(int data) {
                      if (rear == size - 1) {
                          System.out.println("Queue is Full");
                          return;
                      }
                      arr[++rear] = data;
                  }

                  // Dequeue: Remove element from front
                  public void dequeue() {
                      if (front > rear) {
                          System.out.println("Queue is Empty");
                          return;
                      }
                      front++;
                  }

                  // Peek: View front element
                  public void peek() {
                      if (front > rear) {
                          System.out.println("Queue is Empty");
                          return;
                      }
                      System.out.println("Front element: " + arr[front]);
                  }

                  // Print the queue
                  public void printQueue() {
                      if (front > rear) {
                          System.out.println("Queue is Empty");
                          return;
                      }
                      for (int i = front; i <= rear; i++) {
                          System.out.print(arr[i] + " ");
                      }
                      System.out.println();
                  }

                  public static void main(String[] args) {
                      Queue q = new Queue(5);
                      q.enqueue(10);
                      q.enqueue(20);
                      q.enqueue(30);
                      q.printQueue(); // 10 20 30
                      q.peek();       // 10

                      q.dequeue();
                      q.printQueue(); // 20 30
                      q.peek();       // 20
                  }
              }

Output:


              10 20 30
              Front element: 10
              20 30
              Front element: 20

Time & Space Complexity:

  • Enqueue: O(1)
  • Dequeue: O(1)
  • Peek: O(1)
  • Space Complexity: O(n)

Why Use Queues?

  • Useful in real-world scheduling scenarios (CPU, printer).
  • When order of processing matters (FIFO).
  • Foundation for BFS traversal in Graphs and Trees.
